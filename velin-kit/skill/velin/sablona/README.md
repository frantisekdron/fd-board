# Velín – datové repo

Soukromé repo pro tvůj Velín (hlasové ovládací centrum Claude Code session).

- `most/velin_state.json` – stav všech session, zapisuje Dispečer (jediný zdroj pravdy).
- `most/prikazy.json` – fronta pokynů z dashboardu.
- `dispecer/postup.md` – postup, podle kterého pracuje Dispečer.
- `velin/` – dashboard pro Vercel (Root Directory = `velin`).

Repo nech **soukromé** – je v něm přehled tvé práce.
